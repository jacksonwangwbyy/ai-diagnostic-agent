## 硬件抽象定义

### 资源属性：
- **通信方式**：TCP + JSON
- **协议规则**：`json_bytes_length(4字节)` + `jsonbody`

---

## 应用接口说明

> C 表示客户端，S 表示服务端

### 1. 登录接口
- **描述**：连接成功后由客户端发起登录请求
- 请求方向：C -> S
- 响应方向：S -> C

---

### 2. 获取当前所有资源数据和状态接口
- 请求方向：S -> C
- 响应方向：C -> S

---

### 3. 配置更新接口
- 请求方向：S -> C
- 响应方向：C -> S

---

### 4. 传感器去皮操作接口
- 请求方向：S -> C
- 请求参数：
  - `"num"`：表示传感器硬件通道号
- 响应方向：C -> S
- 响应参数：
  - `"status"`：操作完成状态（0 成功，1 失败）
  - `"num"`：传感器硬件通道号

---

### 5. 传感器开始校准操作接口
- 请求方向：S -> C
- 请求参数：
  - `"num"`：传感器硬件通道号
  - `"ratio"`：传感器系数
  - `"weight"`：校准重量值
- 响应方向：C -> S
- 响应参数：
  - `"num"`：传感器硬件通道号
  - `"sensor_value"`：当前传感器实际重量值
  - `"ratio"`：传感器系数值
  - `"status"`：操作完成状态（0 成功，1 失败）

---

### 6. 传感器取消校准操作接口
- 请求方向：S -> C
- 响应方向：C -> S
- 响应参数：
  - `"status"`：操作完成状态（0 成功，1 失败）
  - `"num"`：传感器硬件通道号

---

### 7. 传感器更改接口号操作接口
- 请求方向：S -> C
- 请求参数：
  - `"old_ch"`：要切换的传感器硬件通道号
  - `"new_ch"`：切换后的传感器硬件通道号
- 响应方向：C -> S
- 响应参数：
  - `"status"`：操作完成状态（0 成功，1 失败）
  - `"num"`：传感器硬件通道号

---

### 8. 传感器设置参数操作接口
- 请求方向：S -> C
- 请求参数：
  - `"num"`：传感器硬件通道号
  - `"id"`：物料 ID 编号
  - `"ch_pga"`：放大系数设置（"3" 表示 128 放大系数，"2" 表示 64 放大系数）
- 响应方向：C -> S
- 响应参数：
  - `"status"`：操作完成状态（0 成功，1 失败）
  - `"num"`：传感器硬件通道号

---

### 9. 传感器获取参数操作接口
- 请求方向：S -> C
- 请求参数：
  - `"num"`：传感器硬件通道号
- 响应方向：C -> S
- 响应参数：
  - `"status"`：操作完成状态（0 成功，1 失败）
  - `"id"`：物料 ID 编号
  - `"channel"`：传感器硬件通道号
  - `"use status"`：当前通道号使用情况（1 表示称重传感器，2 表示温度传感器）
  - `"mselPga"`：放大系数设置（"3" 表示 128 放大系数，"2" 表示 64 放大系数）
  - `"ratio"`：传感器系数值
  - `"pare"`：称重传感器原始值

---
