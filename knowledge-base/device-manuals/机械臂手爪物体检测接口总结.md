# 机械臂手爪物体检测接口与实现总结

## 1. 概述

本文档总结了 `bar_middleware` 项目中关于**机械臂手爪上是否有物体**的相关接口和实现。

核心功能：通过读取机械臂 DI（数字输入）信号，判断手爪传感器是否检测到物体（杯子）。

---

## 2. 核心接口

### 2.1 HTTP 接口

**文件位置**: `src/bar_middleware/hw_arm/rokae/api_http.py`

#### 接口 1: `/robot/check_grappawl_cup` (GET)

**功能**: 获取机械臂夹爪的 DI 信号，判断是否有杯子

**参数**:
- `label` (int, 可选): 错误类型标识，范围 0 到枚举长度-1

**返回数据结构**:
```python
ArmDIResponse:
  - grappawl: bool      # 是否支持夹爪功能
  - disignal: bool      # DI 信号值（true=有杯子，false=无杯子）
  - action: str         # 错误动作标识（根据 label 映射）
```

**实现逻辑**:
1. 调用 `arm_comm.get_DI(1, 0)` 获取 DI 信号
2. 调用 `mid_conf.support_grippawl_version()` 检查版本是否支持夹爪
3. 根据 `label` 参数映射到 `GraspError` 枚举获取错误描述
4. 返回结构化响应

**代码位置**: 第 681-733 行

---

#### 接口 2: `/robot/has_grappawl` (GET)

**功能**: 判断当前机器版本是否支持夹爪功能

**返回**:
```python
CustomResponse:
  - success: bool
  - msg: str
  - data: bool  # 是否支持夹爪
```

**实现**: 调用 `mid_conf.support_grippawl_version()` 判断版本

**代码位置**: 第 656-679 行

---

#### 接口 3: `/robot/getDI` (GET)

**功能**: 直接获取 DI 信号原始值

**返回**:
```python
{
  "success": true,
  "msg": "",
  "data": bool  # DI 信号值
}
```

**实现**: 直接调用 `arm_comm.get_DI(1, 0)`

**代码位置**: 第 628-632 行

---

### 2.2 错误类型枚举 (GraspError)

**文件位置**: `src/bar_middleware/hw_arm/rokae/api_http.py` (第 46-76 行)

定义了各种场景下的夹爪检测错误类型：

| 枚举值 | 描述 |
|--------|------|
| ARM_HAS_CUP_BEFORE_DISPENSE | 机械臂夹爪有杯子(落杯前) |
| ARM_NO_CUP_AFTER_DISPENSE | 机械臂夹爪没有杯子(落杯后) |
| ARM_NO_CUP_AT_ICE_DISPENSER | 机械臂夹爪没有杯子(到达落冰口) |
| ARM_NO_CUP_AT_COFFEE_DISPENSER | 机械臂夹爪没有杯子(到达咖啡出液口) |
| ARM_NO_CUP_BEFORE_LID | 机械臂夹爪没有杯子(扣盖前) |
| ARM_CLEAN_MODE_SENSOR_ERROR | 清洗模式时夹爪传感器异常 |

## 3. 底层实现

### 3.1 DI 信号读取

**文件位置**: `src/bar_middleware/hw_arm/rokae/comm.py` (第 505-517 行)

**方法**: `ArmCommunication.get_DI(board: int, port: int)`

**参数**:
- `board`: 板卡编号 (固定为 1)
- `port`: 端口号 (固定为 0)

**返回**: `bool` - DI 信号状态 (true=有物体, false=无物体)

**核心逻辑**:
1. 检查连接状态，未连接则自动初始化
2. 调用 SDK 的 `getDI()` 方法读取信号
3. 检查错误码，失败返回 False
4. 返回传感器状态

**依赖**: `xCoreSDK_python.xMateRobot` SDK

---

### 3.2 版本支持判断

**文件位置**: `src/bar_middleware/conf.py` (第 178-182 行)

**方法**: `MiddleWareConfig.support_grippawl_version()`

**功能**: 判断当前机器版本是否支持夹爪传感器功能

**实现**:
```python
def support_grippawl_version(self):
    if self.bar_version in [BarVersion.V3_2_2.value]:
        return True
    else:
        return False
```

**支持版本**: 仅 `3.2.2` 版本支持夹爪传感器

---

### 3.3 夹爪配置管理

**文件位置**: `src/bar_middleware/hw_arm/rokae/data/grippawl.py`

**类**: `GripperConfig`

**配置文件路径**: `/home/smyze/config/machine/hw_arm/rokae/grippawl.toml`

**配置结构**:
```yaml
using: false              # 是否启用夹爪
version: ["3.2", "3.2.1", "3.2.2"]  # 支持的版本列表
```

**核心方法**:

1. **read_gripper_config()** - 读取配置
   - 文件不存在时自动创建默认配置
   - 确保字段类型正确

2. **update_gripper_config(using, version)** - 更新配置
   - 支持动态修改 using 和 version 字段
   - 自动写回配置文件

## 4. 调用流程

### 4.1 完整调用链路

```
HTTP 请求 (/robot/check_grappawl_cup)
    ↓
api_http.py: check_grappawl_cup()
    ↓
├─ mid_conf.support_grippawl_version()  # 检查版本支持
│   └─ conf.py: 判断 bar_version == "3.2.2"
│
└─ arm_comm.get_DI(1, 0)  # 读取 DI 信号
    └─ comm.py: ArmCommunication.get_DI()
        └─ xCoreSDK_python.xMateRobot.getDI()  # SDK 调用
```

### 4.2 关键判断逻辑

**接口返回逻辑** (`api_http.py` 第 707-730 行):

1. **版本不支持** → `grappawl=False, disignal=False`
2. **版本支持 + DI=True** → `grappawl=True, disignal=True` (有杯子)
3. **版本支持 + DI=False** → `grappawl=True, disignal=False` (无杯子)

### 9.2 业务逻辑封装

**文件位置**: `Quokka251/Backend/Device/Robobarista/Mode/OperatingMode/Cn/Smyze/Function/GripPawlData.cs`

**类**: `GripPawlData`

#### 方法 1: CheckRobotGripPawlNoCupAsync(int label)

**功能**: 检查机械臂夹爪是否**没有**杯子

**参数**: `label` - 错误类型标识（对应 GraspError 枚举索引）

**返回**: `bool` - true=检查通过, false=检查失败（有杯子或异常）

**核心逻辑**:
1. 调用 `RobotHttpClient.CheckGrapPawlCup(label)` 获取夹爪状态
2. 如果不支持夹爪功能 (`grappawl=false`) → 返回 `true` (跳过检查)
3. 如果 `disignal=false` (无杯子) 且有错误消息 → 发布告警事件，返回 `false`
4. 其他情况 → 返回 `true`

**代码示例**:
```csharp
public async Task<bool> CheckRobotGripPawlNoCupAsync(int label)
{
    var midResponse = await robotClient.CheckGrapPawlCup(label);

    // 不支持夹爪，跳过检查
    if (midResponse?.Data == null || midResponse.Data?.grappawl == false)
        return true;

    // 检测到无杯子且有错误消息，发布告警
    if (midResponse.Data.disignal == false && midResponse.Msg != "")
    {
        Logger.Info(_className, $"检查机械臂夹爪没有杯子: {midResponse.Msg}");
        EventBus.Publish(new AlertEvent(...));
        return false;
    }

    return true;
}
```

## 11. 关键要点总结（跨项目）

### 11.1 技术栈
- **后端服务**: bar_middleware (Python + FastAPI)
- **业务系统**: Quokka251 (C# + .NET)
- **通信协议**: HTTP/REST API
- **硬件 SDK**: xCoreSDK_python (机械臂控制)

### 11.2 数据流向
1. C# 业务逻辑调用 → RobotHttpClient
2. HTTP 请求 → bar_middleware API
3. Python 调用 SDK → 机械臂控制器
4. 读取 DI 信号 → 夹爪传感器
5. 返回结果 → C# 业务逻辑处理

### 11.3 错误处理机制
- **版本不支持**: 自动跳过检查，返回 true
- **传感器异常**: 发布告警事件，记录日志
- **网络异常**: 捕获异常，返回 false

### 11.4 应用场景
- 落杯前检查：避免重复落杯
- 取杯后验证：确保成功抓取
- 出液前检查：确保杯子在位
- 清洗模式：传感器状态监控
